# 🕒 Theme Clock – Front-End Development Project

## 📌 Project Overview

Theme Clock is a responsive web application built using HTML5, CSS3, and JavaScript. It displays the current time with an elegant clock interface and includes a light and dark theme option for a better user experience.

The project focuses on JavaScript functionality, DOM manipulation, and modern CSS styling.

## ✨ Key Features

- Real-time clock display
- Analog clock interface
- Light and dark theme toggle
- Interactive user interface
- Responsive design
- Smooth theme transitions
- Automatic time updates

## 🛠️ Technologies Used

- HTML5 – Structure
- CSS3 – Styling and animations
- JavaScript – Clock functionality and theme switching

## 📱 Responsive Design

Designed to work across:
- Desktop
- Laptop
- Tablet
- Mobile devices
